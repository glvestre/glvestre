# Developer Skills Suite

Collection de skills Claude Code pour améliorer le développement, la création de sites web et le web design.

## Skills disponibles

| Commande | Description |
|----------|-------------|
| `/code-quality` | Analyse la qualité du code (ESLint, Stylelint, SonarQube) |
| `/auto-test` | Génère et lance des tests automatiquement (Jest, Mocha, Selenium) |
| `/web-design` | Crée des composants UI et maquettes web (Figma, CSS, React) |
| `/security-scan` | Détecte les vulnérabilités (OWASP Top 10, Snyk, Checkmarx) |
| `/api-builder` | Génère et documente des APIs (Swagger, Postman) |
| `/deploy` | Prépare le déploiement (Docker, GitHub Actions, Cloud) |
| `/auto-docs` | Génère la documentation (MkDocs, JSDoc, Sphinx) |
| `/db-manage` | Gère les bases de données (PostgreSQL, MongoDB, Redis) |
